# 가끔 바나나

**사장님은 문장을 기다리고, 직원은 바나나를 기다립니다.**

무작위 출판사의 사장님이 되어 원숭이 한 마리에게 원고를 맡기는 웹 실험입니다.
직원은 글을 모르지만 키는 잘 누릅니다. 뭘 하는지는 모르겠고, 두드리다 보면 가끔 바나나가 나옵니다.

정현준 / Hyunjoon Jeong

## 이 출판사가 일하는 법

원고를 적거나 외주함에서 긴 글을 받아 나눠 맡깁니다. 원숭이는 무작위로 타이핑하고, 편집부는 **다음에 필요한 글자와 우연히 일치한 글자만** 오려 붙입니다. 문장 전체를 한 번에 맞히는 방식은 아닙니다.

원고가 바뀌어도 피로는 남습니다. 지치면 눈꺼풀과 고개가 내려가고 손이 느려집니다. 바나나는 기운을 회복시킬 뿐, 어떤 글자가 나올 확률을 바꾸지 않습니다.

완성한 원고는 영수증으로 남기거나 한 권의 책으로 묶을 수 있습니다. 책의 마지막 장에는 그 원고에 실제로 들어간 타수, 근무 시간, 바나나가 적힙니다.

> 직원은 이 책을 읽지 않았습니다.

## 실행과 수정

- [GitHub Pages에 올리는 방법](docs/DEPLOY.md)
- [본문·외주·디자인 수정 위치](docs/EDITING.md)

HTML·CSS·JavaScript로 구성되어 있으며 설치나 빌드 없이 배포할 수 있습니다. 원고와 책장은 현재 브라우저에 저장됩니다. 다른 사람이나 기기와 공유되는 서버 저장소는 없습니다.

서체는 Sunflower입니다. 폰트의 라이선스는 [OFL-Sunflower.txt](fonts/OFL-Sunflower.txt)에 포함되어 있습니다.

개발 검증은 Node.js 22 이상에서 `npm test`로 실행합니다. 사이트를 배포하거나 이용할 때 Node.js는 필요하지 않습니다.
